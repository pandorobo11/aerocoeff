Installation
============

The package is not on PyPI; install it from GitHub:

.. code-block:: console

   $ uv add "aerocoeff @ git+https://github.com/pandorobo11/aerocoeff"

This installs the latest ``main``. To pin a version published on
`GitHub Releases <https://github.com/pandorobo11/aerocoeff/releases>`__,
append its tag, for example ``...aerocoeff@v0.1.0``.

``aerocoeff`` requires Python 3.12 or later. NumPy is the only runtime
dependency.
